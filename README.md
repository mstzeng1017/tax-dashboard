# 所得稅 Dashboard

把歷年「綜合所得稅納稅證明書」PDF 拖進來，自動解析+視覺化。

🔗 **線上版**：https://mstzeng1017.github.io/tax-dashboard/

---

## 特色

- 🔒 **100% 本地端**：PDF 在你瀏覽器解析，不會上傳任何伺服器
- 📊 **歷年比較**：本人/配偶所得、扣除額、應納稅額一目瞭然
- 🎯 **自動偵測**：已婚 / 單身依 PDF「配偶姓名」欄位自動判斷
- 📐 **內建級距表**：109-114 年度稅率級距 + 累進差額
- 💾 **JSON 備份**：清快取前可匯出，之後匯入還原
- 🌗 **亮暗模式**

---

## 隱私聲明

| 項目 | 是否上傳 |
|-----|---------|
| 你上傳的 PDF | ❌ 從不上傳 |
| 解析後的數字 | ❌ 從不上傳 |
| 你的 PDF 密碼 | ❌ 從不上傳（只存你瀏覽器 localStorage）|
| 任何個人資料 | ❌ 從不收集 |

dashboard 是**純前端 SPA**，沒有 backend、沒有 API、沒有 cloud 連線。
打開後拔網路線一樣能用 → 證明完全本地運作。

---

## 怎麼用

1. 上 [財政部稅務入口網](https://www.etax.nat.gov.tw/etwmain/etw108w) 用自然人憑證 / 健保卡 / 行動自然人憑證登入
2. 申請「電子稅務文件 → 綜所稅 → 納稅證明書」（處理約 1 小時，下載密碼是身分證號）
3. 把 PDF 拖進 dashboard 的「匯入 PDF」
4. 看圖表
